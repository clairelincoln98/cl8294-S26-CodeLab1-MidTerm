Egg game!

I wanted to create a constant stream of objects that the player controls to get points

It was a bit of a design challenge to get the eggs to not collide with eachother, but also have the fresh eggs change to rotten when they touched the rotten ones (aka the collider layers were set to not recognize each other so I had to do a work around!)

Also had some trouble adding force to the eggs to make them more like a constant stream. 

I think this would improve if the player had a little more control and if the point system was more forgiving. For example, maybe for every 10 eggs you get a point either positive or negative, or maybe have there be multiple baskets so that the player has more screenspace to work with!
